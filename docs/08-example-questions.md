# 8. Example questions

These are **questions you type to the agent**, not the system prompts in [`prompts/`](../prompts/).
The system prompt says who the agent is; a question says what you want to know. This page gives
general questions that work on any dataset, a staged way to explore a dataset you know nothing
about, and examples for the two sample datasets.

## How to ask

```bash
# one question, one run
python agent.py data/factory_sensors.csv "What is in this dataset?"

# interactive: a conversation, where every follow-up sees the earlier answers
python agent.py data/factory_sensors.csv
```

The data file is always the first argument, and it can be any CSV. Every run prints a header with
the model, the data file, the system prompt file (with a short hash of its exact text), the active
flags, and then your question. A saved run therefore records what was asked.

## Exploring an unknown dataset, one question at a time

Use interactive mode and ask these in order. Each answer tells you what to ask next, and the
agent remembers what it already found. You rarely need all of them.

| # | Goal | A general wording that works on any dataset |
|---|---|---|
| 1 | Orient | "What is in this dataset? Explain what each row represents and what each column means." |
| 2 | Data quality | "Check the data quality. What problems do you find (duplicates, missing values, odd labels, impossible values), and how would you fix each one?" |
| 3 | Coverage | "What does the data cover: which time range, which groups or entities? Are there gaps or uneven coverage?" |
| 4 | Consistency | "Check that every numeric column is on a consistent scale and unit across groups and over time." |
| 5 | Distributions | "How are the main numeric columns distributed? Which values look unusual?" |
| 6 | Over time | "How do the key metrics change over time? Look for trends, cycles and sudden changes, and say when each starts." |
| 7 | Segments | "Compare the groups. Which differ most from the others, and by how much?" |
| 8 | Relationships | "Which columns move together? Which relationships look strongest, and which could be coincidence?" |
| 9 | Anomalies | "Find the most unusual records or periods. What could explain each?" |
| 10 | Drill-down | "Take the most important finding and find its cause. What evidence supports it, and what would contradict it?" |
| 11 | Challenge | "What else could explain this? Check the alternatives and tell me how sure you are." |
| 12 | Report | "Estimate the impact and save a short report for someone who has not seen the data." |

Stages 2 to 4 are the ones people skip, and the ones that stop the agent from analysing broken data.
Stage 11 is the cheapest quality check you have.

## Tips

- **One request per question.** "Clean it, find outliers and make three charts" produces a long
  run you cannot steer. Ask for one thing and read the answer.
- **Once you know the columns, name your metric and period.** "Which region underperformed in Q3
  compared to Q2?" beats "How are we doing?"
- **Ask for evidence and for alternatives.** The agent states conclusions confidently. Asking
  "what would contradict this?" makes it look for counter-evidence.
- **Follow-ups keep context only within one session.** In interactive mode they do. A new
  `python agent.py ...` command starts with an empty memory.
- **The same question can give different answers.** The model is not deterministic. For anything
  important, ask twice, or ask a follow-up that checks the first answer.
- **Say so if you want a saved report.** The agent writes one to `reports/` only when you ask, for
  example "...and save a short report". The report starts with your exact question, the data file and
  the date, added automatically.
- **Put limits in the question** when you want them: "use only the last week", "make at most two
  charts", "keep the answer under ten lines".
- **You can add `--review`** to have a second step check the final answer against the code outputs
  (see [05-behaviours.md](05-behaviours.md#--review-a-second-pair-of-eyes)).

## Questions for the sample datasets

Both datasets are generated by scripts, see [07-demo-guide.md](07-demo-guide.md) for how and for
the hidden stories (spoilers).

**Sales data** (`python generate_sales_data.py`, then `data/sales.csv`):

| Question |
|---|
| "Which region underperformed in Q3 compared to Q2, and why?" |
| Follow-up: "How much revenue did that cost us? Estimate it." |
| "Did any region trade margin for growth?" |
| "Which product line is the most profitable, and is that changing over time?" |

**Factory sensor data** (`python generate_factory_data.py`, then `data/factory_sensors.csv`): readings
from eight machines every five minutes for three weeks.

| Question |
|---|
| "Which machine needs attention, and what is the evidence?" |
| "When did the trouble on that machine start? Could it have been noticed earlier?" |
| "Is any shift less productive than the others? By how much?" |
| "Are there gaps, stuck values or unit problems in any sensor?" |
| "How do temperature and vibration relate, per machine?" |

## A recorded session on the factory data (spoilers)

Three real runs on the factory data are saved in [`transcripts/`](transcripts/):
`factory-explore.txt`, `factory-diagnose.txt` and `factory-followups.txt`. They show how a
careful sequence of questions compares with a single question, and they are not flattering to the
agent, which is the point:

- **Exploring (stage 1 and 2).** The agent described the columns well, and found the duplicate
  rows, the missing temperatures and some gaps in the timestamps. It noticed a maximum temperature
  of 152.97 °C and called it "extremes or measurement spikes". It did not notice that this was
  one machine reporting in Fahrenheit.
- **One question: "Which machine needs attention?"** Misled by those Fahrenheit values, one run
  named the wrong machine (M08).
- **The same question in a fresh session** named the right one (M06, the only machine with fault
  readings). So the answer depends on the run, not only on the data.
- **Follow-ups.** Asked to check scales, the agent said they were mostly consistent. Asked for
  trends, it found the rising vibration on M06, and also flagged a rising temperature on M08 that
  is really a unit change. A good next question would have been: *"Look at M08's temperature
  around 20 March. Is that a real change or a change of unit?"*

The lesson: the staged questions found real problems and the single question did not, but
a human still has to look at doubtful findings. The agent also did not check its own earlier
answer until it was asked to.

## Saving a run

```bash
python agent.py data/factory_sensors.csv "Which machine needs attention?" > docs/transcripts/my-run.txt
```

When the output goes to a file or pipe, colors are switched off automatically, so the file is plain
text. Set `NO_COLOR=1` to switch colors off in the terminal too, or `FORCE_COLOR=1` to keep them in
a pipe (for example `| less -R`). Because the header records the question, the prompt file with its
hash, and the flags, a saved run explains itself. If you change `prompts/system.md`, the hash
changes, so you can tell which transcripts used which wording.

## Where to add your own

Add questions for a new dataset to the tables above, under a new heading, and put a one-line
description of the dataset's hidden story in [07-demo-guide.md](07-demo-guide.md). Generated data
files, charts and reports are git-ignored. Transcripts you want to keep go in `docs/transcripts/`.
